========================================
 CLIENTE RECOMENDADO - SERVIDOR H3N-X
========================================

Este paquete es 100% OPCIONAL y va del lado de TU computadora, no del
servidor. Mejora rendimiento y visuales; ningun mod de esta lista da
ventajas de combate ni rompe las reglas del servidor (salvo Gamma Utils,
ver nota abajo).

REQUISITOS
-----------
- Minecraft Java Edition 1.21.11
- Fabric Loader instalado (https://fabricmc.net/use/installer/)
  Elegi Minecraft version 1.21.11 al instalar Fabric.

INSTALACION AUTOMATICA (recomendado)
--------------------------------------
Linux/Mac: corre instalar-h3nx.sh
Windows:   doble clic en instalar-h3nx.bat

INSTALACION MANUAL
--------------------
1. Abri la carpeta .minecraft de tu PC:
     Windows: %appdata%\.minecraft
     Linux:   ~/.minecraft
     Mac:     ~/Library/Application Support/minecraft
2. Copia el contenido de este ZIP (las carpetas mods/, config/,
   shaderpacks/, resourcepacks/) DENTRO de esa carpeta .minecraft.
3. Abri el launcher, elegi el perfil "fabric-loader-1.21.11" y jugá.

NOTA - mods que NO se incluyeron y por que
---------------------------------------------
- FirItemZoom: su unico build publicado es para Minecraft 1.21.8, el
  autor todavia no lo actualizo a 1.21.11 -- incluirlo hubiera roto la
  carga de mods. Si en el futuro sacan una build nueva, se puede sumar.
- ToggleNametags y "Font++": estaban mencionados en la descripcion
  original de DIOSESMC pero NO existian realmente en los archivos del
  modpack que analizamos (quedaron huerfanos de una version vieja) --
  no hay nada que copiar.
- Iris + shader Complementary Unbound: Iris dejo de sacar builds para la
  linea 1.21.x (ya solo desarrolla para los drops 26.x de Mojang), y la
  ultima Iris que existe para 1.21.11 (1.10.7) es incompatible con
  cualquier Sodium reciente (Sodium mismo lo declara explicitamente).
  No hay forma de tener shaders funcionando en este momento sin romper
  el resto del pack. Se puede volver a sumar el dia que Iris saque una
  build compatible.

NOTA SOBRE GAMMA UTILS (vision nocturna)
-------------------------------------------
Viene APAGADO por defecto. Se activa con una tecla configurable (andá a
Opciones -> Controles -> Gamma Utils para asignarla). Es lo unico de este
pack que se podria considerar una ventaja injusta en survival -- lo dejamos
disponible pero es decision tuya si lo usas.

CONFIGURAR LAS IMAGENES DE FANCYMENU
--------------------------------------
Las 4 imagenes ya estan incluidas en:
  config/fancymenu/assets/h3nx_title_screen.png    (menu principal)
  config/fancymenu/assets/h3nx_loading_screen.png  (pantalla de carga)
  config/fancymenu/assets/h3nx_pause_screen.png    (menu de pausa)
  config/fancymenu/assets/h3nx_logo.png            (logo)

FancyMenu no las aplica solo -- hay que asignarlas una vez, a mano, desde
el editor visual del propio mod:
  1. Entra al juego con el modpack instalado.
  2. En el menu principal, abri "Mods" (boton que agrega Mod Menu) y
     busca la config de FancyMenu, o el icono de edicion que FancyMenu
     agrega en cada pantalla (suele ser un lapiz en una esquina).
  3. Usa el editor de FancyMenu para agregar cada imagen como fondo de
     su pantalla correspondiente (Title Screen / Loading Screen / Pause
     Screen). El editor es visual (arrastrar y soltar), no hace falta
     tocar archivos.
  4. Guardá el layout desde el propio editor.

CONECTARSE AL SERVIDOR
------------------------
- El servidor esta en modo "cracked" (no requiere cuenta premium), pero
  usa whitelist: pedile a un admin que te agregue con tu nombre exacto.
- La primera vez que entres vas a tener que registrarte con:
    /register <contraseña> <contraseña>
  y en las siguientes conexiones:
    /login <contraseña>
